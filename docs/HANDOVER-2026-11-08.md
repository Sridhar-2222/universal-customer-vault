## Sign-in difficulties found in the live logs (read only)
1. **"email rate limit exceeded"**: Supabase's built-in email sender allows only a few emails per hour for the whole project; this blocks sign-in codes in a pilot. Main problem.
2. "Email link is invalid or has expired": link used up or expired (some mail apps open links automatically). Typing the 6-digit code avoids this.
3. "Error sending confirmation OTP to provider" for phone numbers: phone sign-in tried with no SMS service connected (from a computer test app, not the live app).
4. "Invalid login credentials" (passwords): from that computer test app.

Options (not started; need the owner's choice):
- **A. Own email sender** (Brevo free ~300/day, or Resend free ~3,000/month) in Supabase → Authentication → SMTP. Recommended first.
- **B. "Continue with Google"** button (free; needs a Google sign-in key). Recommended next.
- C. Code by WhatsApp (Meta per-message fee, approved template).
- D. Code by SMS (paid per SMS, DLT registration in India).
